Politique de confidentialité

Dernière mise à jour : 22 novembre 2026

Les données que vous saisissez

Pétanque Manager sert à organiser des concours de pétanque. Les noms des joueurs et des équipes, les clubs, les concours et les résultats sont enregistrés uniquement sur votre appareil. Je n'y ai pas accès, je ne les collecte pas et je ne les envoie sur aucun serveur. L'application ne demande ni compte ni inscription.

Sauvegarde

La fonction « Exporter » crée un fichier à l'endroit que vous choisissez sur votre appareil. C'est vous qui décidez de le conserver ou de le partager.

Aucune publicité

Pétanque Manager ne contient aucune publicité, aucun traceur et aucun outil d'analyse. Elle ne collecte aucune donnée.

Version Windows

La version Windows (ainsi que l'APK Android téléchargé depuis GitHub) peut contacter GitHub uniquement pour vérifier si une nouvelle version est disponible ; aucune donnée personnelle n'est envoyée.

Statistiques du site

Ce site utilise GoatCounter, un outil de mesure d'audience respectueux de la vie privée : aucun cookie, aucune donnée personnelle ni adresse IP stockée. Il compte uniquement le nombre de visites, les pages vues, le pays, le navigateur et le site d'origine, de façon anonyme.

Enfants

L'application ne s'adresse pas spécifiquement aux enfants de moins de 13 ans.

Vos droits

Vos données personnelles restant sur votre appareil, vous pouvez les consulter, les modifier ou les supprimer à tout moment depuis l'application, ou en la désinstallant.
