# Petanque-Manger
Pétanque Manager L'application pour organiser et gérer vos concours de pétanque, du tirage au classement final.  Pétanque Manager accompagne les organisateurs et les clubs le jour du concours. Vous inscrivez les équipes sur place, vous lancez les tirages et vous suivez les résultats. Tout le reste est calculé automatiquement.
